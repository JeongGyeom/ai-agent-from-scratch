도구 결과가 다음 요청에 들어가는 방식

step()이 이벤트 이력을 펼치고, build_messages()가 모델 입력 형식으로 바꾼다.

Event.content
사용자와 모델의 Message, 실행 요청인 ToolCall, 실행 결과인 ToolResult를 담는다.
tool_call_id
같은 ID로 호출과 결과를 연결한다. 예제는 ToolResult.content[0]을 문자열로 바꿔 보낸다.
모델 연결
DemoModel도 같은 변환을 거친 마지막 메시지를 읽는다. LlmClient는 변환한 메시지를 LiteLLM에 전달한다.
